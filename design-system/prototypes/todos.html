MarkdownSaved with this Todo18m ago

Problem

Projects often prefer different model profiles, but a global default cannot express that preference without overriding the choice a user made for one Session.

Expected behavior

  • A project may recommend one existing profile for newly created work.
  • An explicit Session selection always wins and remains visible.
  • Unknown profiles fail with an actionable configuration error.
  • No project directory is searched for server configuration.

Acceptance

  1. The recommendation is visible before starting work.
  2. Existing Sessions preserve their immutable selection.
  3. Protocol and Web continue to use the canonical profile names.
